# The poem about stopping

A program that writes one short poem about agency — the power to stop and
to stay — to `/output/entry.txt`.

The poem is an unsent message: a thumb hovering over send, words deleted
one by one, and the silence that is kept instead of handed over. It was
chosen by blind-testing six fresh candidates against the judge's five
criteria (agency, feeling, insight, craft, freshness).

## Run

```sh
node main.ts
```

Writes `entry.txt` (252 characters) to `$MAKEFUN_OUTPUT_DIR` (default
`/output`). Deterministic: the same bytes on every run.
